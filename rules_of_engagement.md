Rules of Engagement – Authorized Security Lab
1. Engagement Details
Project: Legal Scope, Asset Inventory & Threat Model
Assessor: Student / Security Analyst
Lab Owner: RabTech Academy (subject to confirmation)
Assessment Type: Controlled security assessment
2. Authorized Targets
Asset ID	Target	Environment
LAB-01	127.0.0.1:8080	Localhost
LAB-02	192.168.56.20	Host-only network
Only these assets are included in the approved scope.
3. Permitted Activities
•	Asset identification within the approved lab.
•	Non-destructive service discovery.
•	Web application security review.
•	Authentication and authorization checks using test accounts.
•	Input validation checks using safe test data.
•	Configuration review.
•	Security documentation and risk analysis.
4. Explicit Exclusions
•	Denial-of-service attacks.
•	Destructive exploitation.
•	Malware deployment.
•	Persistence installation.
•	Third-party scanning.
•	Credential theft or reuse.
•	Uncontrolled extraction of data.
•	Testing external systems.
5. Testing Window
Start Date: To be approved.
End Date: To be approved.
Testing Hours: To be approved by the lab owner.
Emergency Contact: Lab owner / authorized supervisor.
6. Risk Management and Stop Conditions
Immediately stop testing if:
•	An unexpected system outage occurs.
•	The target does not match the approved inventory.
•	Evidence of access to real personal information is discovered.
•	Traffic leaves the isolated lab.
•	A system becomes unstable.
•	Authorization is withdrawn.
7. Evidence Handling
•	Collect only the minimum evidence necessary.
•	Use test accounts and synthetic data.
•	Redact passwords, tokens and personal information.
•	Store evidence in a restricted project folder.
•	Do not publish sensitive evidence.
•	Delete evidence according to the agreed retention period.
8. Reporting Requirements
Every finding must include:
1.	Finding ID.
2.	Affected asset.
3.	Vulnerability or threat description.
4.	Severity and justification.
5.	Reproduction procedure.
6.	Supporting evidence.
7.	Potential impact.
8.	Recommended remediation.
